Defect Inspection · SubspaceAD over frozen DINOv2

Two Branches, One Spine

Registration and inference run an identical preprocessing path — enforced structurally, because pipeline.py is the only implementation and both stages call it. They diverge in exactly one place: the ROI loop, where appearance reads patch vectors and geometry reads the silhouette mask. The two never touch each other's data.

Registration

python -m inspector.register --sku <SKU>

Builds the normal model from golden photos. No gradient training anywhere — the fitted model is a mean vector and an eigenbasis. Note where sku.json enters: at the start, not the end.

Inference

python -m inspector.inspect --sku <SKU> --image <img>

Everything registration fitted arrives as model.npz, along the top. It feeds three different consumers — the reference frame, the score map, and the tolerance test — and those three feeds are the only connection between the two stages. Below them the same spine runs, then the ROI loop. DINOv2 runs once on the whole canvas, so the ROIs slice a map that already exists.

WHY RETAKE IS NOT FAIL

An unusable photo is not a defective part. Reporting a clipped or unsegmentable frame as FAIL would send the operator to scrap a good part instead of retaking the picture — so it gets its own verdict, decided before any scoring happens.

Where the branches differ

They fail on opposite things. That is the whole reason both exist.

Appearance vs geometry, per ROI
Aspect Appearance Geometry
Reads Patch feature vectors → score map Aligned silhouette mask
Compares to Subspace μ, C + position stats geometry_nominals — median + MAD
Decision score ≤ threshold No tolerance violations
Score means max(zresid, zmaha) over valid patches Worst tolerance usage; 1.0 = at the limit
Catches Scratches, stains, burrs, wrong finish Missing or bent tab, chamfer vs square corner
Blind to Logical anomalies — absent metal reads as ordinary background texture Anything that doesn't move the outline, like a scratch across the tab

Which is why sku.json for SKU 8983864641 pairs them over identical boxes:

tab_top_right

appearance · box [930, 80, 280, 230]

Sheet check 1 — the part must have the tab at top right. Catches a damaged or wrongly-finished tab.

tab_top_right_geom

geometry · box [930, 80, 280, 230]

Same box, silhouette instead. A bent-up or missing tab changes the filled area — invisible to appearance.
